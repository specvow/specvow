SpecVow

The spec makes a promise.
The SDK has to keep it.

SpecVow checks a published TypeScript SDK against its OpenAPI spec. When a pull request would break a locked method, CI fails. It does not generate a new SDK.

Read the source

On a pull request

- uses: specvow/specvow@main
  with:
    config: specvow.config.yaml
Breaking
  billing.invoices.create now requires `currency`

exit 2

Exit 2 fails the job. An operation with no method stays in the log and does not fail it.

Fails the job

  • A locked method is gone.
  • The spec now requires a path or query parameter the method does not.
  • The spec now requires a body, or a top-level body field, the method does not.

Does not

  • An operation that has no SDK method.
  • An SDK method that has no operation.
  • Nested object fields. Python is not read yet.

Stainless

Pass stainless.yml. SpecVow pairs each method with the endpoint the generator published, including a path parameter nested in the params object. find_by_status lines up with pets.findByStatus.
